# 操作说明

## 1 编译项目

```bash

编译
进入项目根目录
make

运行主节点 master
make run


从机运行（可选）
make run-slave


```

主机开启在2000端口，从机在2001端口



## 2 存储方法

使用TCP客户端，连接主机



发送命令：(R/S/H)SET,  (R/S/H)GET,  (R/S/H)MOD,  (R/S/H)DEL,  (R/S/H)EXIST

用于从kv引擎的增删改查



主机执行：SAVE

用于保存当前数据到快照snap，该操作会清空aof文件（历史数据已保存，新的操作写入aof）。



从机执行：sync  <IP>  <2000>

连接主机，并向主机发送SYNC命令备份主机数据，此时主机会保存快照并清空aof，并将所有snap数据发送到从机。从机保存至data目录下。



## 3 技术要点

主从项目文件相同，直接拷贝到从机即可使用。

支持命令行批处理

支持任意长度kv值

支持四种存储数据结构

支持全量、增量持久化

项目采用非阻塞IO技术，防止传输大文件出现线程卡死的情况。
